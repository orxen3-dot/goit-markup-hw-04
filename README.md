# WebStudio: Layout and Interface Styling

A WebStudio agency landing page developed as part of the GoIT HTML/CSS course.

## About the project

This iteration continues the multi-section WebStudio page and refines its layout and interface styling. The page includes a consistent header, hero section, feature list, team, portfolio, and footer.

## Highlights

- Reusable page containers
- Navigation with an active-link style
- Structured feature, team, and portfolio sections
- Component-oriented CSS files
- Styled links, buttons, and content blocks

## Technologies

- HTML5
- CSS3
- Flexbox
- Modern Normalize
- Google Fonts (Roboto and Raleway)

## Run locally

Clone the repository and open `index.html` in a browser. No package installation is required.

## Learning focus

Refining page layout, applying reusable CSS patterns, and improving the consistency of a multi-section website.
